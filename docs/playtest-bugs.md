# Playtest bugs

Bugs found during LAN playtesting sessions. Not fixed yet — logged for follow-up.

## 2026-08-22

- **Quick Tetris / Line Clear Sprint**: pressing the Up key does not rotate the piece.
- **Bubble Pop**: can assign/give a color that has no bubbles left on the board (already empty).
- **Live ranking/scoreboard**: only reflects the current mini-game's score, not the cumulative session total.
- **Pixel Split**: objects/pieces should not all align the same way (lack of variety in layout).
- **Simon**: when the sequence repeats the same color twice in a row, the playback is too quick to follow.
- **Balloon Chicken** (referred to as "balloon pop"): displayed player names are not the real ones.
- **Pixel Hoops** (referred to as "pixel hope"): the green target/scoring area should shrink each time (increasing difficulty), currently stays the same size.
- **Round result screen**: the round winner and the round summary are shown on separate screens; should be combined into one.
- **Fruit Catch**: bombs are not visually clear (hard to distinguish from fruits); caught fruits should disappear after being caught but don't.
- **Sudoku Race**: once a cell is filled with the correct number, it should be locked/blocked from further edits.

- **Layout**: the screen should be fixed-size; a scroll bar should not be needed.

## Feature requests / ideas (not bugs)

- Friends asked for new luck-based games, e.g. Pachinko-style / gambling-style mini-games.
